# Syntecxhub Artificial Intelligence Internship - Week 1

This repository contains the solutions for **Week 1 Tasks** as part of the **Syntecxhub Artificial Intelligence Internship Program**.

---

## 📌 Included Projects

### 1. Maze Solver using A* Search Algorithm (`a_star_maze.py`)
- **Objective:** Find the shortest path in a 2D grid/maze from a Start position to a Goal position while navigating around obstacles (walls).
- **Key Concepts:** 
  - Graph/Grid representation using nodes.
  - Priority Queue (`heapq`) for tracking node evaluation.
  - Heuristic function using **Manhattan Distance**.
  - Handling path reconstruction and unreachable goal scenarios.

---

### 2. Rule-Based Expert System (`expert_system.py`)
- **Objective:** Build an inference engine using multi-step **Forward Chaining** to draw logical conclusions based on user-provided facts and pre-defined rules.
- **Key Concepts:**
  - Fact Base & Rule Engine (`If-Then` logic).
  - Multi-step forward chaining inference loop.
  - Logging step-by-step reasoning paths for visual tracking.
